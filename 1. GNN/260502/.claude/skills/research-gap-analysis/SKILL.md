# Research Gap Analysis

본 논문과 최신 연구를 대조하여 기술적 갭을 정량적·정성적으로 분석하는 절차.

## 1. 분석 5축 정의

논문의 갭은 5개 축으로 분리하여 비교한다. 각 축은 독립적으로 평가 가능해야 하며, 축 간 trade-off도 인지한다.

| 축 | 평가 항목 |
|---|---|
| **데이터** | 샘플 수, 다양성, 레이블 품질, 시뮬레이션/실험 비율, 일반화 분포 |
| **모델** | backbone 아키텍처, 파라미터 수, 입출력 구조, 표현력 |
| **기법** | 학습 손실, 정규화, 데이터 증강, optimization, hyperparameter |
| **응용** | 대상 부품/시스템, 사용 시점(설계/검증), 시간 범위(static/transient), 시계열 여부 |
| **평가** | 지표 종류, region 정의, baseline 비교, ablation, 통계 신뢰도 |

## 2. SWOT 작성

본 논문의 강점과 약점을 4분면으로 정리:

```
             내부 (논문 자체)              외부 (환경/동향)
강점/기회   | Strengths                   | Opportunities
            | - 양산 휠 데이터 사용         | - 시계열 GNN 동향
            | - geometry-aware augmentation | - chassis 부품 확장 시장
            |                              |
약점/위협   | Weaknesses                  | Threats
            | - 시계열 미지원              | - Equivariant GNN의 우위
            | - 단일 부품 한정             | - Foundation model 경쟁
```

**작성 원칙**:
- 추상적 표현(예: "혁신적", "제한적") 대신 정량/구체 (예: "샘플 수 580으로 일부 최신 연구의 1/10 수준")
- 강점도 정직하게 평가 — 모든 측면을 우수로 적지 않는다
- 위협은 학술 경쟁뿐 아니라 산업 트렌드(예: SDV, OEM의 자체 surrogate 개발)도 고려

## 3. 5축 갭 매트릭스 작성

```markdown
## 5축 갭 매트릭스

| 축 | 본 논문 | 최신 연구 평균 | SOTA | 갭 정량/정성 | 보완 방향 |
|---|---|---|---|---|---|
| 데이터 | 580 샘플, 단일 도메인 | 1k~10k 샘플 | DrivAerNet 8k+ | -1 order | 미사용 데이터 + augmentation 강화 |
| 모델 | MeshGraphNets (15-20 layers, 64 hidden) | (조사 결과) | (조사 결과) | (구체) | (구체) |
| 기법 | Weighted L₂ + geo-edge aug | (조사) | (조사) | (구체) | (구체) |
| 응용 | wheel 단일, max stress 시점 | (조사) | (조사) | (구체) | (구체) |
| 평가 | Top 20% MAPE, KLD | (조사) | (조사) | (구체) | (구체) |
```

**작성 시 주의**:
- "최신 연구 평균"은 조사한 5건 이상의 중앙값 또는 분포 표현
- "SOTA"는 가장 우수한 1건. 단, 데이터셋이 다르면 직접 비교 불가 명시
- "갭 정량/정성"은 구체적 격차 (예: "-1 order", "+2 metric points")
- "보완 방향"은 단순 "X 추가하라"가 아닌 "X 데이터 + Y baseline + Z 평가"로 구체화

## 4. 핵심 갭 Top 5 도출

매트릭스의 모든 갭 중 다음 기준으로 우선순위:

1. **영향도** — 보완 시 본 논문 가치 향상 정도
2. **실행 가능성** — 6~12개월 내 해결 가능 여부
3. **차별성** — 보완 시 학술/산업 차별화 정도
4. **의존성** — 다른 갭 해결의 선결 조건 여부

각 핵심 갭마다 다음 형식으로 기술:

```markdown
### Gap N: [이름]

- **현황**: 본 논문에서 어떻게 처리되고 있는가
- **문제**: 왜 갭으로 평가되는가 (인용 근거 포함)
- **영향**: 미해결 시 어떤 한계로 이어지는가
- **해결 단서**: 최신 연구에서 어떤 접근이 가능한가 (인용)
- **우선순위 점수**: 영향도 × 실행 가능성 (1-5 척도)
```

## 5. 본 논문이 선도하는 영역

갭만 보면 부정적 보고서가 되므로, 본 논문이 동향 대비 우월한 영역도 정직하게 평가:

- **양산 사양 데이터 활용** — 대부분의 GNN 연구는 toy mesh / 단순 형상
- **자동화된 데이터 추출 파이프라인** — 산업 적용 가능성
- **Edge augmentation의 geometry-aware 변형** — 단순 random rewiring 대비 우월
- **명확한 evaluation region 정의** — Top 20% region이 산업적 의미

각 영역마다 "왜 우월한가" + "어떻게 강화할 것인가" 기재.

## 7. 작성 시 자주 하는 실수

| 실수 | 회피 방법 |
|---|---|
| "본 논문이 시계열을 못한다"식 단순 비판 | "본 논문은 max stress 시점만, [Pfaff 2021]처럼 rollout 기반 시계열로 확장 가능" |
| 갭 = 보완 방향이 1대1 매칭 | 1개 갭에 여러 보완 방향, 1개 보완 방향이 여러 갭 해결 가능 명시 |
| 모든 갭에 동일 우선순위 | Top 5만 핵심으로, 나머지는 부록 / "관찰된 갭" 정도로 |
| 신규성만 강조 | 신규성 + 실행 가능성 + 산업 적용성 균형 |
