# Future Research Proposal

갭 분석 결과를 실행 가능한 연구 로드맵으로 변환하는 절차.

## 1. SMART 기준

각 연구 방향은 다음 5개 기준을 모두 만족해야 한다:

| 기준 | 의미 | 좋은 예 | 나쁜 예 |
|---|---|---|---|
| **S**pecific | 무엇을 할지 명확 | "MeshGraphNets에 SE(3)-equivariant layer 적용" | "성능을 더 높인다" |
| **M**easurable | 측정 가능한 목표 | "Top 5% MAPE 5% 미만" | "정확도 향상" |
| **A**chievable | 달성 가능 | "기존 데이터 + 6개월 작업으로" | "1주일에 완성" |
| **R**elevant | 본 논문과 관련성 | "휠 강도 예측의 회전 불변성 보장" | "전혀 다른 도메인" |
| **T**ime-bound | 기간 명시 | "6개월 / 12개월 / 24개월" | "언젠가" |

## 2. 단/중/장기 분류 기준

| 분류 | 기간 | 특징 |
|---|---|---|
| **단기** | ≤6개월 | 기존 데이터/모델 활용. 새로 수집 / 신규 아키텍처 불필요 |
| **중기** | 1~2년 | 신규 데이터 수집 또는 새 모델 아키텍처 1~2개 도입 |
| **장기** | 3~5년 | 패러다임 전환, 산업 통합, 신규 R&D 자원 필요 |

본 논문의 경우 후보 방향:

**단기 후보**:
- 미사용 데이터(745-290) 추가 학습 → Top 20% MAPE 개선
- Region 정의 세분화 (Top 5%, Top 10%) 평가 추가
- Loss function γ 하이퍼파라미터 grid search
- 다른 baseline (FNO, GCN 등)과 정량 비교

**중기 후보**:
- 시계열 GNN (rollout-based MeshGraphNets) — 충격 전체 과정 예측
- SE(3)-equivariant GNN 도입 — 회전 불변성 보장
- Suspension arm 등 다른 chassis 부품 framework 확장
- Foundation pretraining (다양한 휠 형상) → fine-tuning

**장기 후보**:
- Foundation model for chassis CAE
- Real-time deployment (양산 설계 도구 통합)
- 실험 데이터 통합 hybrid (digital twin)
- Generative wheel design (GNN + diffusion)

## 3. 각 방향의 표준 형식

```markdown
### N.X [방향 이름]

- **분류**: 단기 / 중기 / 장기
- **목표**: [정량적 KPI]
  예: "Top 5% region MAPE 5% 미만 달성, KLD 0.003 미만"
- **방법**:
  1. [단계 1]: 데이터 측면
  2. [단계 2]: 모델 측면
  3. [단계 3]: 학습 측면
  4. [단계 4]: 평가 측면
- **데이터/리소스**:
  - 데이터: [필요 데이터셋과 규모]
  - 컴퓨팅: [GPU 사양/시간 추정]
  - 인력: [필요 역량]
- **Baseline 및 기대 성능 향상**:
  - Baseline: 본 논문 (Top 20% MAPE 7.0%)
  - 기대: [정량적 향상폭]
  - 근거: [관련 연구 인용]
- **리스크**:
  - 기술 리스크: [기술적 불확실성]
  - 일정 리스크: [지연 가능성]
  - 자원 리스크: [데이터/GPU 부족 가능성]
- **선결 조건** (있으면): [먼저 완료해야 할 다른 방향]
- **우선순위 점수**: [높음/중간/낮음] + 근거
- **관련 인용**: [학술 근거 1-3건]
```

## 4. 우선순위 평가 기준

각 방향마다 다음 4축으로 평가 (1-5):

| 축 | 의미 |
|---|---|
| **영향도** | 본 논문 가치 향상 정도 |
| **실행 가능성** | 자원/시간 측면 가능성 |
| **차별성** | 학술/산업 차별화 정도 |
| **확장성** | 다른 응용으로 확장 가능성 |

종합 점수 = 영향도 × 실행 가능성 (가중치 우선) + 차별성 + 확장성

Top 5 방향을 도출하여 `5.4 추천 우선순위 Top 5` 섹션에 별도 정리.

## 5. 후속 논문 후보 주제 도출

연구 방향 중 1~2년 내 학술 발표 가능한 것들을 별도 논문 후보로:

```markdown
### 논문 후보 N: [제목]

- **타깃 학회/저널**: SAE, JSAE, NeurIPS, ICLR, CMAME, JMPS 등
- **핵심 기여 (1-2 문장)**:
- **차별점 (vs 본 논문 + vs 최신 SOTA)**:
- **필요 실험**: [3-5개 실험 항목]
- **소요 시간 추정**: [작성 + 실험 + 리뷰]
```

본 논문 저자의 학술 활동 패턴(JSAE 제출)을 고려하여 학회 추천도 함께.

## 7. 작성 시 자주 하는 실수

| 실수 | 회피 방법 |
|---|---|
| 모든 방향에 동일한 디테일 | Top 5는 상세, 나머지는 핵심만 |
| Achievable 무시 | "1년에 5개 방향 동시 진행" 금지. 자원 기반 현실적 평가 |
| Baseline 누락 | 모든 방향에 본 논문 또는 다른 연구 baseline 명시 |
| 인용 없는 주장 | "이 기법이 효과적"이면 반드시 근거 인용 |
| 산업 적용성 무시 | 본 논문 저자가 OEM 소속임을 인지, 양산 / TRL 측면 고려 |

## 8. 갭 분석과의 연결

각 연구 방향은 `_workspace/03_gap-analysis.md`의 어느 갭을 해결하는지 명시:

```markdown
- **해결하는 갭**: Gap 2 (시계열 미지원), Gap 4 (단일 부품)
```

복수 갭을 동시 해결하는 방향은 우선순위 가산점.
